# C++ 模板编程

## 模板的本质

模板不是真正的代码，而是**生成代码的模具**。编译器拿着你给的类型，把模具"印"出真正的代码。这个过程叫做**实例化（Instantiation）**。

> [!important] 核心理解
> 模板 = 空壳代码，编译时根据传入的类型自动替换生成真正的函数/类。

---

## 一、函数模板

### 基本语法

```cpp
// 没有模板时，每种类型都要写一遍（太累了）
int    add(int a, int b)    { return a + b; }
float  add(float a, float b){ return a + b; }
double add(double a, double b){ return a + b; }

// 用模板，一次搞定
template <typename T>    // T 是占位符，代表"某种类型"
T add(T a, T b) {
    return a + b;
}
```

### 使用方式

```cpp
add(1, 2);          // 编译器自动推导 T = int（隐式）
add(1.5f, 2.5f);    // T = float（隐式）
add<double>(1, 2);  // 手动指定 T = double（显式）
```

> [!note] `typename` vs `class`
> 在模板参数声明中，`template<typename T>` 和 `template<class T>` **完全等价**，没有任何区别。

## 二、类模板

### 基本语法

```cpp
template <typename T>
struct Box {
    T value;              // T 类型的成员变量

    void set(T v) {       // 参数也是 T
        value = v;
    }

    T get() {             // 返回值也是 T
        return value;
    }
};
```

### 使用方式

```cpp
Box<int> intBox;          // 类模板必须手动指定类型
intBox.set(42);

Box<std::string> strBox;
strBox.set("hello");
```

### 常见例子

```cpp
std::vector<int>          // vector 就是类模板
std::map<string, int>     // map 也是
TArray<FVector>           // UE 的 TArray 也是
```

## 三、多个模板参数

```cpp
template <typename K, typename V>
struct Pair {
    K key;
    V value;
};

Pair<std::string, int> p;
p.key = "age";
p.value = 25;
```

这就是 `std::pair` 和 `TMap` 的原理。

## 四、非类型模板参数（Non-type Template Parameter）

模板参数不一定是类型，也可以是**值**：

```cpp
// N 代表一个整数值（编译期常量）
template <int N>
struct FixedArray {
    int data[N];      // 编译期确定大小
    int size() { return N; }
};

FixedArray<10> arr;   // 数组大小为 10
FixedArray<100> arr2; // 数组大小为 100
// 注意：这两个是完全不同的类型！
```

### 混合使用

```cpp
template <typename T, int Size>
struct StaticVector {
    T data[Size];
};

StaticVector<float, 3> vec3;   // 3 个 float
StaticVector<double, 4> vec4;  // 4 个 double
```

### 能当非类型参数的东西

- 整数（`int`, `size_t`, `bool`, 枚举）
- 指针、引用
- C++20 后：浮点数、字面量类型
- **成员指针**（高级用法）

## 五、模板特化（Specialization）

"对特定类型做特殊处理"。

### 全特化

```cpp
// 通用版本（主模板）
template <typename T>
struct Printer {
    void print(T value) {
        std::cout << value << std::endl;
    }
};

// 全特化：专门给 bool 写一个版本
template <>                    // 注意：尖括号是空的！
struct Printer<bool> {         // 指定具体类型 bool
    void print(bool value) {
        std::cout << (value ? "true" : "false") << std::endl;
    }
};
```

### 偏特化（Partial Specialization）

只特化一部分参数：

```cpp
// 主模板
template <typename T, typename U>
struct Pair {
    T first;
    U second;
};

// 偏特化：当两个参数相同时
template <typename T>
struct Pair<T, T> {
    T first;
    T second;
    bool areEqual() { return first == second; }
};

// 偏特化：当第二个参数是指针时
template <typename T, typename U>
struct Pair<T, U*> {
    T first;
    U* second;
    U deref() { return *second; }
};
```

> [!warning] 注意
> 函数模板**不能**偏特化，只有类模板可以。函数模板用重载来替代偏特化。

## 六、模板实例化

### 隐式实例化（自动）

你用了，编译器就自动生成：

```cpp
std::vector<int> v;     // 编译器自动生成 vector<int>
add(1, 2);              // 自动生成 int add(int, int)
```

99% 的情况都是隐式实例化。

### 显式实例化（手动强制）

不管你用不用，命令编译器立刻生成：

```cpp
template struct Box<int>;              // 强制生成 Box<int>
template int add<int>(int, int);       // 强制生成 add<int>
```

用途：
- 控制编译速度（把实例化集中到一个 .cpp 文件）
- 触发副作用（比如那段私有访问 demo）

## 七、`typename` 关键字的两种含义

### 含义 1：声明模板参数

```cpp
template <typename T>   // "T 是一个类型参数"
template <class T>      // 完全一样
```

### 含义 2：消除歧义（依赖类型名）

```cpp
template <typename T>
void foo() {
    // 编译器不知道 T::value_type 是类型还是变量
    // 必须加 typename 提示
    typename T::value_type x;  // "T::value_type 是一个类型！"
}
```

> [!tip] 为什么需要？
> 因为 `::` 后面的东西可能是类型（`using type = int;`），也可能是静态变量（`static int count;`）。在模板中编译器无法确定，需要你用 `typename` 告诉它。

## 八、`using` 类型别名

### 基本用法

```cpp
using Integer = int;           // 等价于 typedef int Integer;
using StringVec = std::vector<std::string>;
```

### 在 struct 内使用（类型萃取的基础）

```cpp
template <typename T>
struct TypeInfo {
    using type = T;
    using pointer = T*;
    using reference = T&;
};

TypeInfo<int>::type       // → int
TypeInfo<int>::pointer    // → int*
```

### 标准库工具原理

```cpp
// std::remove_pointer 的简化实现
template <typename T>
struct remove_pointer {
    using type = T;          // 默认：不变
};

template <typename T>
struct remove_pointer<T*> {  // 偏特化：如果是指针
    using type = T;          // 去掉一层指针
};

remove_pointer<int*>::type   // → int
remove_pointer<int**>::type  // → int*
```

## 九、`inline static` 成员（C++17）

```cpp
template <typename T>
struct Config {
    inline static int count = 0;  // 直接在头文件里定义+初始化
};
```

C++17 之前需要分开写：

```cpp
// .h 文件
template <typename T>
struct Config {
    static int count;  // 只是声明
};

// .cpp 文件
template <typename T>
int Config<T>::count = 0;  // 定义
```

## 十、成员指针（Pointer to Member）

> [!note] 这是理解那段私有访问 demo 的前置知识

### 普通指针 vs 成员指针

```cpp
struct Foo {
    int x = 42;
    float y = 3.14f;
};

// 普通指针 — 指向具体对象的地址
Foo obj;
int* p = &obj.x;

// 成员指针 — 指向"Foo 类中 x 的偏移量"，不绑定任何对象
int Foo::* mp = &Foo::x;
```

### 使用成员指针

```cpp
Foo obj;
int Foo::* mp = &Foo::x;

obj.*mp = 100;        // 等价于 obj.x = 100

Foo* ptr = &obj;
ptr->*mp = 200;       // 等价于 ptr->x = 200
```

### 类型语法

| 声明 | 含义 |
|------|------|
| `int Foo::*` | 指向 Foo 类中 int 成员的指针 |
| `float Foo::*` | 指向 Foo 类中 float 成员的指针 |
| `void (Foo::*)()` | 指向 Foo 类中 void() 成员函数的指针 |

## 十一、宏与 Token Pasting（`##`）

### `##` — 令牌粘接

把两个标记拼成一个新标记：

```cpp
#define CONCAT(A, B) A##B

CONCAT(My, Class)  // → MyClass
CONCAT(get, Value) // → getValue
```

### `#` — 字符串化

把宏参数转成字符串字面量：

```cpp
#define STRINGIFY(X) #X

STRINGIFY(Hello)   // → "Hello"
STRINGIFY(123)     // → "123"
```

### UE 中的常见应用

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite)
float Health;

DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnHealthChanged, float, NewHealth);
```

这些宏内部大量使用 `##` 拼接生成类名、函数名等。

## 十二、综合实例 — 私有成员访问技巧

> [!caution] 高级技巧
> 这是 Level 4 的内容，结合了上面所有知识点。理解了前面的基础后再看这里。

### 原理

利用**显式模板实例化时不检查 private 访问权限**的特性，配合成员指针，在编译期获取私有成员的地址。

### 完整代码

```cpp
// 步骤 1：桥接类 — 存储成员指针
template <typename Member>
class TPrivateAccess {
public:
    inline static typename Member::Type MemberPtr;
};

// 步骤 2：触发器 — 利用静态初始化赋值
template <typename Member, typename Member::Type Ptr>
struct TStaticPtrInit {
    struct FConstructPrivateAccess {
        FConstructPrivateAccess() {
            TPrivateAccess<Member>::MemberPtr = Ptr;
        }
    };
    inline static FConstructPrivateAccess TriggerConstruct;
};

// 步骤 3：宏封装
#define DECLARE_PRIVATE_ACCESS(Typename, MemberName, MemberType) \
    struct Typename##MemberName##Access { \
        using Type = MemberType Typename::*; \
    }; \
    template struct TStaticPtrInit<Typename##MemberName##Access, &Typename::MemberName>;

#define PRIVATE_ACCESS(Typename, MemberName) \
    TPrivateAccess<Typename##MemberName##Access>::MemberPtr
```

### 使用

```cpp
struct Secret {
private:
    int value = 42;
};

DECLARE_PRIVATE_ACCESS(Secret, value, int)

int main() {
    Secret obj;
    obj.*PRIVATE_ACCESS(Secret, value) = 999;  // 成功修改私有成员！
}
```

### 执行流程

1. 宏展开 → 生成 `SecretvalueAccess` 结构体 + 显式实例化
2. 显式实例化 `TStaticPtrInit<..., &Secret::value>` — **绕过 private 检查**
3. 静态成员 `TriggerConstruct` 初始化 → 构造函数执行
4. 构造函数把 `&Secret::value` 存入 `TPrivateAccess::MemberPtr`
5. 用户通过 `PRIVATE_ACCESS` 宏取出成员指针并使用
