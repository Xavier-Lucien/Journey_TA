# x86-64 汇编语言快速入门

> [!note] 本文目标
> 不是教你写汇编，而是让你**能看懂**编译器生成的汇编代码。重点是 x86-64 架构 + Windows 平台（MSVC/VS 反汇编窗口看到的就是这种）。

---

## 一、汇编的基本世界观

汇编语言只认识三样东西：

| 概念 | 说明 |
|------|------|
| **寄存器** | CPU 内部的超高速小格子，数量有限（十几个） |
| **内存** | 一个巨大的字节数组，用地址访问 |
| **指令** | 对寄存器和内存做的操作（读、写、算、跳） |

没有变量名、没有类型、没有作用域、没有类。一切都是**地址**和**字节**。

---

## 二、寄存器一览

### 什么是寄存器？

寄存器是 CPU 内部的**超高速存储格子**。CPU 算东西必须先把数据放进寄存器，算完再写回内存。你可以把寄存器理解为 CPU 的"手"——它一次只能拿几样东西（寄存器数量有限），需要更多东西就去内存（桌子）上拿。

### x64 有多少个通用寄存器？

**正好 16 个。** 分两组：

- **前 8 个**：从 32 位时代继承，有英文缩写名（rax、rbx、rcx...）
- **后 8 个**：64 位时代新增，纯数字编号（r8、r9、r10...r15）

### 第一组：老 8 个寄存器（有历史名字）

| 寄存器 | 名字来源 | 实际用途（Windows x64） |
|--------|---------|----------------------|
| `rax` | Accumulator | **函数返回值**放这里；也用于乘除法 |
| `rbx` | Base | 通用寄存器（被调用者保存） |
| `rcx` | Counter | **第 1 个参数** / this 指针 |
| `rdx` | Data | **第 2 个参数** |
| `rsi` | Source Index | 通用（名字是历史遗留，现在没特殊含义） |
| `rdi` | Destination Index | 通用（同上） |
| `rbp` | Base Pointer | **栈帧基址**——局部变量用 `[rbp-xx]` 访问 |
| `rsp` | Stack Pointer | **栈顶指针**——永远指向栈的最高处，别碰 |

### 第二组：64 位新增的 8 个寄存器（纯编号）

| 寄存器 | 用途（Windows x64） |
|--------|-------------------|
| `r8` | **第 3 个参数** |
| `r9` | **第 4 个参数** |
| `r10` | 通用（调用者保存） |
| `r11` | 通用（调用者保存） |
| `r12` | 通用（被调用者保存） |
| `r13` | 通用（被调用者保存） |
| `r14` | 通用（被调用者保存） |
| `r15` | 通用（被调用者保存） |

> [!tip] "调用者保存" vs "被调用者保存"
> - **调用者保存**：如果你调用别的函数，这个寄存器的值可能被覆盖，想保留就自己先存
> - **被调用者保存**：函数里如果要用这个寄存器，必须先把原值存起来、用完还原
>
> 不需要背，看反汇编时知道有这个规则就行。

### 特殊寄存器（不在 16 个通用之内）

| 寄存器 | 用途 |
|--------|------|
| `rip` | 指令指针——CPU 下一条要执行的指令地址（你不能直接改它） |
| `rflags` | 标志寄存器——`cmp` 比较的结果存这里，跳转指令读这里 |
| `xmm0` ~ `xmm15` | **浮点寄存器**（16个），float/double 运算用这些 |

### 一个寄存器到底多大？

**每个通用寄存器物理上都是 64 位（8 字节）。** CPU 里就是一个 8 字节的格子，只有一个，不是四个。

但是 C++ 的数据类型大小不同：

| C++ 类型 | 大小 | 需要寄存器的多少位？ |
|----------|------|-------------------|
| `char` / `bool` | 1 字节 | 8 位 |
| `short` | 2 字节 | 16 位 |
| `int` / `float` | 4 字节 | 32 位 |
| `long long` / 指针 / `double` | 8 字节 | 64 位 |

所以 CPU 允许你**用不同的名字只操作同一个格子的一部分**：

```
假设 rax 里存着 0x1122334455667788：

位编号: 63                              31              15      7      0
       ┌───────────────────────────────┬───────────────┬───────┬───────┐
       │ 11 22 33 44                   │ 55 66         │  77   │  88   │
       └───────────────────────────────┴───────────────┴───────┴───────┘

用 rax 读 → 0x1122334455667788  (完整64位，操作指针/long long时用)
用 eax 读 → 0x55667788          (只取低32位，操作int时用)
用 ax  读 → 0x7788              (只取低16位，操作short时用)
用 al  读 → 0x88                (只取最低8位，操作char时用)
用 ah  读 → 0x77                (取第8~15位，ax的高半，现在几乎不用)
```

> [!important] 核心理解
> **rax / eax / ax / al 不是四个不同的寄存器！**
> 它们是**同一个物理格子的不同取用范围**。就像一根尺子，你可以量整根（rax），也可以只量后半段（eax），也可以只量最后几厘米（al）。

### 为什么编译器不全用 rax？

因为**省空间、更快**：

```asm
mov eax, 10      ; 操作32位，机器码短（操作int时用这个）
mov rax, 10      ; 操作64位，机器码多一个字节前缀（操作指针时才用）
```

编译器会根据你变量的类型**自动选最合适的宽度**。

### 你在 VS 反汇编里看到不同名字时怎么理解？

| 看到 | 说明正在操作 | 对应 C++ 类型 |
|------|------------|--------------|
| `rax`, `rcx`, `rdx`... | 8 字节数据 | 指针、`long long` |
| `eax`, `ecx`, `edx`... | 4 字节数据 | `int`、`float`(地址) |
| `ax`, `cx`, `dx`... | 2 字节数据 | `short`（很少见） |
| `al`, `cl`, `dl`... | 1 字节数据 | `char`、`bool` |

> [!tip] 什么时候用哪个？
> - 操作 `int`（4字节）→ 用 `eax`, `ecx` 等 32 位名
> - 操作 `long long` / 指针（8字节）→ 用 `rax`, `rcx` 等 64 位名
> - 操作 `char`（1字节）→ 用 `al`, `cl` 等 8 位名

### 两组寄存器的命名规则对比

**老 8 个（有名字的）**：加前缀

| 64 位 | 32 位 | 16 位 | 8 位 |
|--------|--------|--------|-------|
| **r**ax | **e**ax | ax | al |
| **r**bx | **e**bx | bx | bl |
| **r**cx | **e**cx | cx | cl |
| ...以此类推 | | | |

**新 8 个（纯编号的）**：加后缀

| 64 位 | 32 位 | 16 位 | 8 位 |
|--------|--------|--------|-------|
| r8 | r8**d** | r8**w** | r8**b** |
| r9 | r9**d** | r9**w** | r9**b** |
| r10 | r10**d** | r10**w** | r10**b** |
| ...以此类推 | | | |

> [!note] 后缀含义
> - `d` = dword（双字 = 32位）
> - `w` = word（字 = 16位）
> - `b` = byte（字节 = 8位）

## 三、指令格式

### Intel 语法（MSVC / Visual Studio 用的）

```asm
操作码   目标, 源
mov      eax, 42        ; eax = 42（数据从右往左流）
add      eax, ecx       ; eax = eax + ecx
```

### AT&T 语法（GCC 默认）

```asm
操作码   源, 目标
movl     $42, %eax      ; eax = 42（数据从左往右流）
addl     %ecx, %eax     ; eax = eax + ecx
```

> [!warning] 方向相反！
> - Intel 语法：`目标, 源`（VS 反汇编看到的）
> - AT&T 语法：`源, 目标`（GCC -S 输出的）
>
> 本文统一用 **Intel 语法**。

## 四、最常用指令分类

### 4.1 数据传送

| 指令 | 含义 | 示例 |
|------|------|------|
| `mov dst, src` | 把 src 复制到 dst | `mov eax, 42` → eax = 42 |
| `lea dst, [addr]` | 取地址（不访问内存） | `lea rax, [rbp-8]` → rax = rbp-8 的地址 |
| `movzx dst, src` | 零扩展（小→大） | `movzx eax, al` → 把8位扩展到32位 |
| `movsx dst, src` | 符号扩展（小→大） | `movsx eax, al` → 保留符号位扩展 |
| `push src` | 压栈（rsp -= 8, [rsp] = src） | `push rbp` |
| `pop dst` | 弹栈（dst = [rsp], rsp += 8） | `pop rbp` |
| `xchg a, b` | 交换 a 和 b 的值 | `xchg eax, ebx` |

> [!note] mov 不能内存到内存
> `mov [rax], [rbx]` 是**非法**的。必须通过寄存器中转：
> ```asm
> mov ecx, [rbx]    ; 先读到寄存器
> mov [rax], ecx    ; 再从寄存器写入
> ```

### 4.2 算术运算

| 指令 | 含义 | 等价 C++ |
|------|------|---------|
| `add dst, src` | dst += src | `a += b` |
| `sub dst, src` | dst -= src | `a -= b` |
| `inc dst` | dst += 1 | `a++` |
| `dec dst` | dst -= 1 | `a--` |
| `neg dst` | dst = -dst | `a = -a` |
| `imul dst, src` | dst *= src（有符号） | `a *= b` |
| `idiv src` | rax / src → 商在eax，余在edx | `a / b`, `a % b` |

### 4.3 位运算

| 指令 | 含义 | 等价 C++ |
|------|------|---------|
| `and dst, src` | dst &= src | `a & b` |
| `or dst, src` | dst \|= src | `a \| b` |
| `xor dst, src` | dst ^= src | `a ^ b` |
| `not dst` | dst = ~dst | `~a` |
| `shl dst, n` | 左移 n 位 | `a << n` |
| `shr dst, n` | 逻辑右移 n 位 | `(unsigned)a >> n` |
| `sar dst, n` | 算术右移（保留符号） | `(signed)a >> n` |

> [!tip] xor 清零技巧
> `xor eax, eax` 等价于 `mov eax, 0`，但更快（只要1字节编码，CPU 特殊优化）。你会在编译器输出中经常看到。

### 4.4 比较与跳转

| 指令 | 含义 |
|------|------|
| `cmp a, b` | 计算 a - b，结果不保存，只设置标志位 |
| `test a, b` | 计算 a & b，结果不保存，只设置标志位 |

比较之后，用条件跳转指令：

| 指令 | 含义 | 适用场景 |
|------|------|---------|
| `je` / `jz` | 相等 / 零 | `==` |
| `jne` / `jnz` | 不相等 / 非零 | `!=` |
| `jl` | 小于（有符号） | `<` |
| `jle` | 小于等于 | `<=` |
| `jg` | 大于（有符号） | `>` |
| `jge` | 大于等于 | `>=` |
| `ja` | 大于（无符号） | `>` (unsigned) |
| `jb` | 小于（无符号） | `<` (unsigned) |
| `jmp` | 无条件跳转 | `goto` |

### 4.5 函数调用

| 指令 | 含义 |
|------|------|
| `call addr` | 压入返回地址，跳到 addr |
| `ret` | 弹出返回地址，跳回去 |

## 五、内存寻址模式

方括号 `[]` 表示"访问这个地址处的内存"：

| 写法 | 含义 | 用途 |
|------|------|------|
| `[rax]` | 读地址 rax 处的值 | 指针解引用 `*p` |
| `[rbp-8]` | rbp 往低地址偏 8 字节 | 局部变量 |
| `[rcx+4]` | rcx 地址 + 4 | 结构体成员 `obj.y` |
| `[rax+rcx*4]` | rax + rcx×4 | 数组访问 `arr[i]` |
| `[rax+rcx*4+8]` | rax + rcx×4 + 8 | 结构体数组 `arr[i].field` |

### 通用公式

```
[base + index * scale + displacement]

base:   基址寄存器（任意通用寄存器）
index:  索引寄存器（除 rsp 外）
scale:  1, 2, 4, 或 8（乘数，对应数据类型大小）
displacement: 立即数偏移（常量）
```

### 大小标注（操作数长度）

```asm
mov   byte ptr [rax], 0       ; 写 1 字节
mov   word ptr [rax], 0       ; 写 2 字节
mov   dword ptr [rax], 0      ; 写 4 字节
mov   qword ptr [rax], 0      ; 写 8 字节
```

| 前缀 | 大小 | 对应 C++ 类型 |
|------|------|--------------|
| `byte ptr` | 1 字节 | `char`, `bool` |
| `word ptr` | 2 字节 | `short` |
| `dword ptr` | 4 字节 | `int`, `float` |
| `qword ptr` | 8 字节 | `long long`, `double`, 指针 |

## 六、函数调用约定（Windows x64）

### 参数传递

| 参数 | 整数/指针 | 浮点 |
|------|----------|------|
| 第 1 个 | `rcx` | `xmm0` |
| 第 2 个 | `rdx` | `xmm1` |
| 第 3 个 | `r8` | `xmm2` |
| 第 4 个 | `r9` | `xmm3` |
| 第 5+ | 栈上 | 栈上 |

### 返回值

- 整数/指针：`rax`
- 浮点：`xmm0`

### 栈帧结构

```
高地址
┌────────────────────────────┐
│ 调用者的局部变量            │
├────────────────────────────┤
│ 返回地址（call 自动压入）   │  ← 函数入口时 rsp 指向这里
├────────────────────────────┤
│ 保存的 rbp（push rbp）     │  ← rbp 指向这里
├────────────────────────────┤
│ 局部变量 1  [rbp-8]        │
│ 局部变量 2  [rbp-16]       │
│ ...                        │  ← rsp 指向这里（栈顶）
└────────────────────────────┘
低地址
```

### 典型函数开头和结尾

```asm
; 函数开头（prologue）
push  rbp           ; 保存旧的栈帧基址
mov   rbp, rsp      ; 建立新栈帧
sub   rsp, 32       ; 给局部变量留空间

; ... 函数体 ...

; 函数结尾（epilogue）
add   rsp, 32       ; 释放局部变量空间
pop   rbp           ; 恢复旧栈帧
ret                 ; 返回
```

## 七、标志位（Flags）

`cmp` 和 `test` 指令不存结果，只设置标志位：

| 标志 | 名称 | 设置条件 |
|------|------|---------|
| ZF | Zero Flag | 结果为 0 |
| SF | Sign Flag | 结果为负（最高位为 1） |
| CF | Carry Flag | 无符号溢出 |
| OF | Overflow Flag | 有符号溢出 |

条件跳转指令读取这些标志来决定是否跳转：

```asm
cmp   eax, ebx     ; 计算 eax - ebx，设置标志位
je    .equal        ; 如果 ZF=1（相等），跳转
jl    .less         ; 如果 SF≠OF（有符号小于），跳转
```

## 八、读懂汇编的技巧

### 8.1 识别函数调用

```asm
mov   ecx, 42         ; 准备第1参数
mov   edx, 100        ; 准备第2参数
call  some_function   ; 调用
; 返回值在 eax
```

### 8.2 识别 if/else

```asm
cmp   eax, 0          ; if (x == 0)
jne   .else_branch    ; 不等则跳到 else
; ... then 分支 ...
jmp   .end_if         ; 跳过 else
.else_branch:
; ... else 分支 ...
.end_if:
```

### 8.3 识别循环

```asm
    mov   ecx, 0          ; i = 0
.loop:
    cmp   ecx, 10         ; i < 10?
    jge   .end            ; 不满足则退出
    ; ... 循环体 ...
    inc   ecx             ; i++
    jmp   .loop           ; 回到循环头
.end:
```

### 8.4 识别数组访问

```asm
; arr[i]，其中 arr 基址在 rax，i 在 ecx，int 类型（4字节）
mov   edx, [rax + rcx*4]    ; edx = arr[i]
```

### 8.5 识别结构体成员

```asm
; player->hp，其中 player 在 rcx，hp 偏移为 0，mp 偏移为 4
mov   eax, [rcx]        ; player->hp
mov   edx, [rcx+4]      ; player->mp
movss xmm0, [rcx+8]     ; player->speed (float)
```

## 九、常见编译器"套路"

| 你看到的汇编 | 编译器在做什么 |
|-------------|--------------|
| `xor eax, eax` | 清零（比 `mov eax, 0` 更快） |
| `test eax, eax` + `je` | 判断是否为 0（`if (x == 0)` 或 `if (!ptr)`） |
| `lea eax, [rcx+rcx*2]` | 乘以 3（`x * 3`，比 `imul` 快） |
| `shl eax, 2` | 乘以 4（左移 = 乘以 2 的幂） |
| `sar eax, 1` | 除以 2（算术右移） |
| `mov eax, [rcx]` + `call [rax]` | 虚函数调用（读 vptr → 调 vtable） |
| `rep movsb` | `memcpy`（批量复制） |
| `nop` | 空操作（对齐用） |

## 十、浮点指令速查

浮点数用 `xmm` 寄存器和 SSE 指令：

| 指令 | 含义 |
|------|------|
| `movss xmm0, [addr]` | 读取 float（单精度） |
| `movsd xmm0, [addr]` | 读取 double（双精度） |
| `addss xmm0, xmm1` | float 加法 |
| `subss xmm0, xmm1` | float 减法 |
| `mulss xmm0, xmm1` | float 乘法 |
| `divss xmm0, xmm1` | float 除法 |
| `comiss xmm0, xmm1` | float 比较（设置标志位） |
| `cvtsi2ss xmm0, eax` | int → float 转换 |
| `cvttss2si eax, xmm0` | float → int 转换（截断） |

> [!tip] ss vs sd vs ps vs pd
> - `ss` = Scalar Single（单个 float）
> - `sd` = Scalar Double（单个 double）
> - `ps` = Packed Single（4个 float 并行）
> - `pd` = Packed Double（2个 double 并行）

## 十一、实战：完整例子逐行注释

### C++ 源码

```cpp
struct Vec2 {
    float x, y;
};

float dot(Vec2* a, Vec2* b) {
    return a->x * b->x + a->y * b->y;
}
```

### 编译器输出（MSVC, Release /O2）

```asm
; rcx = a, rdx = b
dot:
    movss   xmm0, [rcx]       ; xmm0 = a->x（偏移0）
    mulss   xmm0, [rdx]       ; xmm0 = a->x * b->x
    movss   xmm1, [rcx+4]     ; xmm1 = a->y（偏移4）
    mulss   xmm1, [rdx+4]     ; xmm1 = a->y * b->y
    addss   xmm0, xmm1        ; xmm0 = 两个乘积之和
    ret                        ; 返回 xmm0（float 返回值）
```

> [!note] 没有函数开头/结尾（prologue/epilogue）
> 因为这个函数很简单，没有局部变量，编译器优化掉了 push/pop rbp 和 sub rsp。

## 十二、学习路径建议

1. **先能"看懂"** — 在 VS 反汇编窗口对照 C++ 看（本文目标）
2. **多用 godbolt.org** — 写一小段 C++，看右边汇编，调优化等级对比
3. **记住常见套路** — `xor eax, eax`、`test + je`、`lea` 乘法等
4. **不需要"写"汇编** — 除非做底层优化或逆向工程

> [!tip] 推荐资源
> - [Compiler Explorer (godbolt.org)](https://godbolt.org/) — 在线看汇编
> - [x86 指令参考](https://www.felixcloutier.com/x86/) — 查指令含义
> - VS 调试 → 反汇编窗口 — 看你自己代码的汇编
